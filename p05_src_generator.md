# Src-layout generator

## 1. Generate a flat project for the next version

Start in `projectgen-flat/`, with its environment active.

```bash
projectgen projectgen-src -t flat -d ..
deactivate
cd ../projectgen-src
```

`-t flat` is required: the previous generator still defaults to simple.
The generated package is named `projectgen_src`; its `cli.py` is only a skeleton.

## 2. Reorganize manually

1. Create `src/`.
2. Move `projectgen_src/` under `src/` and rename it to `projectgen/`.
3. Copy the six `.py` modules from `projectgen-flat/projectgen/` into `src/projectgen/`, replacing the skeleton `cli.py`.
4. Keep the empty `__init__.py` and the newly created `env/`.
5. Change the README heading to `# projectgen`.

```text
projectgen-src/
├── env/
├── src/
│   └── projectgen/
│       ├── __init__.py
│       ├── cli.py
│       ├── environment.py
│       ├── myparser.py
│       ├── naming.py
│       ├── projectfiles.py
│       └── structure.py
├── pyproject.toml
└── README.md
```

The package remains `projectgen`; its location changes. Relative imports remain valid.

## 3. Configure the generator

Replace the generated `pyproject.toml` completely:

```toml
[build-system]
requires = ["setuptools>=77.0.3"]
build-backend = "setuptools.build_meta"

[project]
name = "projectgen"
version = "0.1.0"
description = "Python project generator"
requires-python = ">=3.10"
dependencies = []

[project.scripts]
projectgen = "projectgen.cli:main"

[tool.setuptools.packages.find]
where = ["src"]
include = ["projectgen", "projectgen.*"]
```

The generated names `projectgen-src` / `projectgen_src` are replaced with `projectgen`.
The package search location is now `src`.

## 4. Add src support

Keep `naming.py` and `environment.py` unchanged.
Replace these four modules:

### `src/projectgen/myparser.py`

```python
import argparse

from .naming import project_name


def parse_arguments():
    parser = argparse.ArgumentParser(description='Create a Python project')
    parser.add_argument(
        'name', nargs='?', type=project_name,
        help='Project name (default: project-YYYYMMDDHHMMSS)'
    )
    parser.add_argument(
        '-t', '--type', choices=['simple', 'flat', 'src'], default='src',
        help='Project type (default: src)'
    )
    parser.add_argument(
        '-d', '--directory', default='.',
        help='Existing parent directory (default: current directory)'
    )
    parser.add_argument(
        '-n', '--no-venv', action='store_true',
        help='Do not create a virtual environment'
    )
    parser.add_argument('--data', action='store_true', help='Create data directory')
    parser.add_argument(
        '--notebooks', action='store_true', help='Create notebooks directory'
    )

    return parser.parse_args()
```

### `src/projectgen/structure.py`

```python
def create_simple(project):
    project.mkdir()


def create_optional_directories(project, data, notebooks):
    if data:
        (project / 'data').mkdir()
    if notebooks:
        (project / 'notebooks').mkdir()


def create_flat(project, package):
    project.mkdir()
    package_dir = project / package
    package_dir.mkdir()
    (package_dir / '__init__.py').touch()
    return package_dir


def create_src(project, package):
    project.mkdir()
    package_dir = project / 'src' / package
    package_dir.mkdir(parents=True)
    (package_dir / '__init__.py').touch()
    return package_dir
```

### `src/projectgen/projectfiles.py`

```python
def create_package_cli(package_dir):
    content = """def main():
    pass


if __name__ == '__main__':
    main()
"""
    (package_dir / 'cli.py').write_text(content, encoding='utf-8')


def create_readme(project, name):
    (project / 'README.md').write_text(f'# {name}\n', encoding='utf-8')


def create_pyproject(project, name, package, where):
    content = f'''[build-system]
requires = ["setuptools>=77.0.3"]
build-backend = "setuptools.build_meta"

[project]
name = "{name}"
version = "0.1.0"
description = "Python project generated by projectgen"
requires-python = ">=3.10"
dependencies = []

[project.scripts]
"{name}" = "{package}.cli:main"

[tool.setuptools.packages.find]
where = ["{where}"]
include = ["{package}", "{package}.*"]
'''
    (project / 'pyproject.toml').write_text(content, encoding='utf-8')
```

### `src/projectgen/cli.py`

```python
from pathlib import Path

from .environment import create_environment
from .myparser import parse_arguments
from .naming import default_name, package_name
from .projectfiles import create_package_cli, create_pyproject, create_readme
from .structure import create_flat, create_optional_directories, create_simple
from .structure import create_src


def main():
    args = parse_arguments()
    name = args.name or default_name()
    project = Path(args.directory).expanduser().resolve() / name

    if args.type == 'simple':
        create_simple(project)

    else:
        package = package_name(name)
        if args.type == 'flat':
            package_dir = create_flat(project, package)
            where = '.'
        else:
            package_dir = create_src(project, package)
            where = 'src'
        create_package_cli(package_dir)
        create_readme(project, name)
        create_pyproject(project, name, package, where)

    create_optional_directories(project, args.data, args.notebooks)
    if not args.no_venv:
        create_environment(project)

    print(f'Created {args.type} project: {project}')


if __name__ == '__main__':
    main()
```

## 5. Install and compare

Activate the new environment:

Windows PowerShell:

```powershell
.\env\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source env/bin/activate
```

Before installation, run from `projectgen-src/`:

```bash
python -m projectgen.cli -h
```

Expected in this new environment: `No module named projectgen`.
The current directory contains `src/`, not the package directly.

```bash
python -m pip install -e .
python -m projectgen.cli -h
projectgen -h
```

Both now work.

## 6. Test the final layouts

```bash
projectgen test_src_default -n
projectgen test_src_flat -t flat -n --data
projectgen test_src_simple -t simple -n --notebooks
projectgen test_src_env
```

| Project | Check |
|---|---|
| `test_src_default` | `src/test_src_default/`, TOML, README; no environment |
| `test_src_flat` | `test_src_flat/` package and `data/` |
| `test_src_simple` | Only `notebooks/` |
| `test_src_env` | Src structure plus `env/` |

For the src output, check that TOML uses `where = ["src"]`.
Generated `cli.py` files are starting points for future code.

Test the installed generator from outside the source directory:

```bash
cd ..
projectgen test_src_outside -n
cd projectgen-src
```
