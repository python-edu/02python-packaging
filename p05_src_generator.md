# Add src project support

## Goal

Extend the generator so that it can create three project types:

```text
simple
flat
src
```

`simple` and `flat` stay unchanged.

`src` should create:

```text
my-src-project/
├── env/
├── data/
├── notebooks/
├── src/
│   └── my_src_project/
│       ├── __init__.py
│       └── cli.py
├── pyproject.toml
└── README.md
```

From this stage, `src` will be the default project type.

---

## 1. Create the new stage

Open a terminal in `projectgen-flat` and activate its environment.

### Windows PowerShell

```powershell
.\env\Scripts\activate
```

### Linux / macOS

```bash
source env/bin/activate
```

Create a new project for this stage:

```bash
projectgen projectgen-src -d ..
```

Deactivate the old environment:

```bash
deactivate
```

Go to the new project:

```bash
cd ../projectgen-src
```

Copy these files from `projectgen-flat` into `projectgen-src`:

```text
cli.py
environment.py
myparser.py
naming.py
projectfiles.py
structure.py
pyproject.toml
```

## 2. Add src directory creation

Add this function to `structure.py`:

```python
def create_src(project, package):
    project.mkdir()
    (project / 'data').mkdir()
    (project / 'notebooks').mkdir()

    package_dir = project / 'src' / package
    package_dir.mkdir(parents=True)
    (package_dir / '__init__.py').touch()

    return package_dir
```

Change `create_flat()` so that it also returns the package directory:

```python
def create_flat(project, package):

    (project / 'data').mkdir()
    (project / 'notebooks').mkdir()

    package_dir = project / package

    return package_dir
```

## 3. Update project file creation

Change `create_package_cli()` so that it receives the package directory directly:

```python
def create_package_cli(package_dir):
    content = '''def main():
    pass


if __name__ == '__main__':
    main()
'''

    (package_dir / 'cli.py').write_text(
        content,
        encoding='utf-8'
    )
```

Change `create_pyproject()` so that it can use either the project root or `src` as the package search location:

```python
def create_pyproject(project, project_name, package, where):
    content = f'''[build-system]
requires = ["setuptools>=77.0.3"]
build-backend = "setuptools.build_meta"

[project]
name = "{project_name}"
version = "0.1.0"
description = "Python project generated by projectgen"
requires-python = ">=3.10"
dependencies = []

[project.scripts]
{project_name} = "{package}.cli:main"

[tool.setuptools.packages.find]
where = ["{where}"]
include = ["{package}*"]
'''

    (project / 'pyproject.toml').write_text(
        content,
        encoding='utf-8'
    )
```

The complete `projectfiles.py` should now be:

## 4. Add the src project type

Change the `--type` argument in `myparser.py`:

```python
parser.add_argument(
    '-t', '--type',
    choices=['simple', 'flat', 'src'],
    default='src',
    help='Project type: simple, flat or src (default: src)'
)
```

The complete `myparser.py` should now be:

```python
import argparse


def parse_arguments():
    parser = argparse.ArgumentParser(
        description='Create a Python project'
    )

    parser.add_argument(
        'name', nargs='?',
        help='Project name (default: project-YYYYMMDDHHMMSS)'
    )

    parser.add_argument(
        '-t', '--type',
        choices=['simple', 'flat', 'src'],
        default='src',
        help='Project type: simple, flat or src (default: src)'
    )

    parser.add_argument(
        '-d', '--directory',
        default='.',
        help='Parent directory (default: current directory)'
    )

    parser.add_argument(
        '-n', '--no-venv',
        action='store_true',
        help='Do not create a virtual environment'
    )

    return parser.parse_args()
```

## 5. Update `cli.py`

Add `create_src` to the structure imports:

```python
from structure import create_flat, create_simple, create_src
```

Use the returned package directory for both installable layouts:

```python
if args.type == 'simple':
    create_simple(project)

elif args.type == 'flat':
    package = package_name(name)
    package_dir = create_flat(project, package)
    create_package_cli(package_dir)
    create_readme(project, name)
    create_pyproject(project, name, package, '.')

elif args.type == 'src':
    package = package_name(name)
    package_dir = create_src(project, package)
    create_package_cli(package_dir)
    create_readme(project, name)
    create_pyproject(project, name, package, 'src')
```

The complete `cli.py` should now be:

```python
from pathlib import Path

from environment import create_environment
from myparser import parse_arguments
from naming import default_name, package_name
from projectfiles import create_package_cli, create_pyproject, create_readme
from structure import create_flat, create_simple, create_src


def main():
    args = parse_arguments()
    name = args.name or default_name()
    project = Path(args.directory).expanduser().resolve() / name

    if args.type == 'simple':
        create_simple(project)

    elif args.type == 'flat':
        package = package_name(name)
        package_dir = create_flat(project, package)
        create_package_cli(package_dir)
        create_readme(project, name)
        create_pyproject(project, name, package, '.')

    elif args.type == 'src':
        package = package_name(name)
        package_dir = create_src(project, package)
        create_package_cli(package_dir)
        create_readme(project, name)
        create_pyproject(project, name, package, 'src')

    if not args.no_venv:
        create_environment(project)

    print(f'Created {args.type} project: {project}')


if __name__ == '__main__':
    main()
```
